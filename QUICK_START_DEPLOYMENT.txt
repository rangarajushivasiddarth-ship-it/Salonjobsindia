QUICK START GUIDE - HOSTINGER + PLAYSTORE DEPLOYMENT
=====================================================

BRO'S QUICK ANSWERS:

Q1: How to deploy to Hostinger?
Answer: Push to GitHub → Hostinger clones it → npm install → npm run start

Q2: Will admin & database be same everywhere?
Answer: YES! One backend (Vercel Blob) = same data everywhere

Q3: Can I publish to PlayStore?
Answer: YES! Already PWA-ready. Just deploy to Hostinger first, then publish.


STEP-BY-STEP (15 minutes):
═════════════════════════════════════════════════════════════════════════

PHASE 1: PREPARE FOR HOSTINGER (5 minutes)
───────────────────────────────────────────────────────────────────────

Step 1: Push to GitHub
  $ cd /path/to/project
  $ git init
  $ git add .
  $ git commit -m "Production ready - Salon Jobs India"
  $ git push origin main

DONE! Your code is backed up and ready to deploy.


PHASE 2: DEPLOY TO HOSTINGER (5 minutes)
──────────────────────────────────────────────────────────────────────

Step 1: Login to Hostinger
  - Go to: hostinger.com
  - Login to your account
  - Open Control Panel

Step 2: Clone Your Repository
  - Click on cPanel
  - Find "Git Version Control" (or "Git®")
  - Click "Create/Clone Repository"
  - Paste your GitHub repo URL (from Step 1)
  - Click "Create"
  - Hostinger auto-clones and installs everything

Step 3: Start Your App
  - Go to cPanel Terminal
  - Run: npm run start
  - You should see: "Ready on http://..."

Step 4: Test Your App
  - Open: https://yourdomain.com
  - Your app is LIVE!

DONE! Your app is running on Hostinger!


PHASE 3: PREPARE FOR PLAYSTORE (5 minutes)
────────────────────────────────────────────────────────────────────────

PWA files already created:
  ✓ /public/manifest.json
  ✓ /public/sw.js
  ✓ /components/service-worker-register.tsx

Your app is already PWA-ready!

Step 1: Create Google Play Developer Account
  - Go to: https://play.google.com/console
  - Pay: $25 one-time fee
  - Create account

Step 2: Install Bubblewrap (tool to generate APK)
  $ npm install -g @bubblewrap/cli

Step 3: Generate APK
  $ bubblewrap init --manifest=/path/to/manifest.json
  (This creates: app.aab file)

Step 4: Upload to Play Console
  - Create new app
  - Upload the APK file
  - Fill in app details
  - Submit for review

DONE! Your app is on PlayStore!

TROUBLESHOOTING:
════════════════════════════════════════════════════════════════════════

Q: App won't start on Hostinger?
A: Check Terminal for errors. Common issue: npm install didn't complete.
   Run: npm install
   Then: npm run start

Q: Domain shows "404 Not Found"?
A: Wait 5-10 minutes for DNS to update. Check Hostinger control panel
   that domain is pointing to public_html folder.

Q: Admin can't see payments?
A: Make sure admin is logged in. Refresh the page. Check browser console
   for errors.

Q: PlayStore app won't install?
A: Check that APK is properly signed. Use Bubblewrap official tool.
   Verify manifest.json is correct.
