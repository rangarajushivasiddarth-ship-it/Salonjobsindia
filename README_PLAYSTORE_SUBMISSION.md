## IF YOU GET STUCK

### Common Issues & Solutions

**"Android Studio won't install"**
→ Check your computer has Java installed
→ Download JDK from Oracle first

**"Can't find app-release.aab"**
→ In Android Studio → View → Tool Windows → Build
→ Scroll to find file path

**"Build fails with error"**
→ Read the error message
→ Google the exact error message
→ Check Android Studio documentation

**"Upload says my bundle is invalid"**
→ Make sure package name matches: com.fitonze.salonjobsindia
→ Make sure using API 24+
→ Rebuild and try again

**"Google rejected my app"**
→ Read rejection email carefully
→ Understand specific issue
→ Fix it
→ Resubmit

**Can't upload screenshots?**
→ Make sure size is exactly 1080 × 1920
→ Try different format (PNG vs JPG)
→ Check file isn't corrupted
