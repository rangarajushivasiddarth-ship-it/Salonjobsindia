1. HOW TO DEPLOY TO HOSTINGER WITH YOUR DOMAIN?

Option A (Recommended): Use GitHub + Hostinger Git Integration
─────────────────────────────────────────────────────────────────────────

Step 1: Push to GitHub
  $ git init
  $ git add .
  $ git commit -m "Production deployment"
  $ git push origin main

Step 2: In Hostinger Control Panel
  - Login to Hostinger
  - Go to cPanel
  - Find "Git Version Control"
  - Click "Create/Clone Repository"
  - Paste your GitHub repo URL
  - Hostinger auto-clones and installs dependencies

Step 3: Start Your App
  - Go to Terminal in cPanel
  - Run: npm run start
  - Your app starts automatically

Step 4: Connect Domain
  - Domain is already configured by Hostinger
  - Open: https://yourdomain.com
  - Your app is LIVE!

Option B: Manual Upload via cPanel File Manager
─────────────────────────────────────────────────────────────────────────

Step 1: Build Your App
  $ pnpm build

Step 2: Upload Files
  - Login to Hostinger
  - Go to cPanel File Manager
  - Navigate to public_html
  - Upload: .next, public, package.json, package-lock.json

Step 3: Install & Run
  - Go to Terminal
  - Run: npm install
  - Run: npm run start

Step 4: Access
  - Open: https://yourdomain.com

3. HOW TO PUBLISH TO PLAYSTORE AS WEB APP?

Your app is now PWA-ready!
─────────────────────────────────────────────────────────────────────────

Files already created:
  ✓ /public/manifest.json - App metadata
  ✓ /public/sw.js - Service worker for offline
  ✓ /components/service-worker-register.tsx - Registration

Step 1: Deploy to Hostinger (from #1 above)
  - Your domain must be HTTPS (Hostinger provides free SSL)
  - Your app must be accessible at https://yourdomain.com

Step 2: Create Google Play Developer Account
  - Go to: https://play.google.com/console
  - Pay $25 one-time fee
  - Create account

Step 3: Generate APK for PlayStore
  - Install Bubblewrap: npm install -g @bubblewrap/cli
  - Run: bubblewrap init --manifest=/path/to/manifest.json
  - This generates a signed APK file

Step 4: Upload to Google Play Console
  - Create new app in Play Console
  - Upload APK
  - Fill app details
  - Add screenshots
  - Add description

Step 5: Submit for Review
  - Submit to Google review team
  - Wait 1-3 days for approval
  - App goes LIVE on PlayStore

Step 6: Your App on PlayStore
  - Users download from PlayStore
  - It opens your Hostinger domain inside app shell
  - No download needed, always fresh
  - Admin & data same as web
