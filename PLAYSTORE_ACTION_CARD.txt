STEP-BY-STEP (3-4 HOURS TOTAL)

DAY 1: SETUP
─────────────
1. Gather info: name, email, address, phone
2. Prepare: App icon (512x512), banner (1024x500), 5-8 screenshots (1080x1920)
3. Go to: https://play.google.com/console
4. Pay: $25 one-time developer fee
5. Create app: "Salon Jobs India"
6. Fill in: Privacy policy URL, terms URL, support email

DAY 2: BUILD
─────────────
7. Download: https://developer.android.com/studio (900MB)
8. Create project:
   Name: SalonJobsIndia
   Package: com.fitonze.salonjobsindia
   Min SDK: API 24

9. Edit file: AndroidManifest.xml
   → Add web app configuration (copy from guide)

10. Edit file: MainActivity.kt
    → Add code to open your website (copy from guide)

11. Add: App icon from logo.png

12. Create: Signing key (SAVE FOREVER!)
    Build → Generate Signed Bundle/APK
    Create keystore → Save .jks file

13. Build: Release bundle (app-release.aab)
    Takes 2-5 minutes

DAY 2: SUBMIT
──────────────
14. Go to: Google Play Console
15. Upload: app-release.aab file
16. Add: 5-8 screenshots (1080x1920 PNG/JPG)
17. Add: Descriptions, app icon, banner
18. Click: "Review release"
19. Click: "Start rollout to Production"
20. Click: "Confirm" → SUBMITTED!

DAY 3: WAIT
────────────
21. Google reviews (2-24 hours)
22. Check status: Release dashboard
23. Approved? → Share app link everywhere!
    Rejected? → Fix issues → Resubmit

IF YOU GET STUCK

"Build won't compile?"
→ Check Java version: java -version
→ Should be 11 or higher
→ Download JDK if missing

"Can't find app-release.aab?"
→ Android Studio → View → Tool Windows → Build
→ Look for file path in output
→ Usually in: app/release/app-release.aab

"Upload fails?"
→ Check package name matches: com.fitonze.salonjobsindia
→ Verify file size 5-15 MB
→ Try again

"Google rejected app?"
→ Read rejection email
→ Fix the specific issue
→ Resubmit (usually approved 2-4 hours)
